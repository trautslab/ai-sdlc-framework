## 🎯 Criterios de Inclusión
Para que una referencia o artículo se catalogue en este directorio, debe aportar:
1. **Evidencia empírica o teórica** sobre las capacidades y límites de los LLMs / Agentes.
2. **Implicaciones directas para la arquitectura de software** (gobernanza, aislamiento, verificación determinista).
3. **Acciones aplicables al framework** para mantenerlo a la vanguardia frente a modelos futuros.
